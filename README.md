# Net Mirror

A cinematic movie and series streaming interface designed for mobile and desktop.

## Project
- Premium dark streaming UI
- Trending, movies, series and genre sections
- Search overlay and detail modal
- Responsive mobile-first layout
- API adapter point in `app.js`

## Important
Do not commit private API keys to this public repository. If the API uses a secret key, connect it through a server-side proxy or serverless function. Actual playback should use authorized stream URLs supplied by the API.
